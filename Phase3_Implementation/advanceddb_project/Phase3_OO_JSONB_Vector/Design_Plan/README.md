# Phase 3 Design Plan

The design plan is included in the team's [final combined technical report and design plan](../Technical_Report/Phase%203%20Technical%20Report%20and%20Design%20Plan.docx), beginning at the **Design Plan** heading. The course allows the plan to be submitted as part of the technical report.

The plan covers:

- Purpose and links to the existing Phase 2 tables and keys.
- The Property class hierarchy, class-table mapping, and the rejected single-table and concrete-table alternatives.
- The authoritative location of relational, subclass, JSONB and searchable text data.
- JSONB boundaries, validation, examples and update behavior.
- Source text, the data-readiness review, search evaluation and maintenance.

The same Word document includes the technical report, diagrams and contribution table. [Requirements_Checklist.md](Requirements_Checklist.md) maps the requirements to executable files and evidence.
